# بلاغ

مساعد لصناعة محتوى موثّق يعرّف بالإسلام عبر اللغات والثقافات.

مشاركة في **تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي**، المسار الثاني: صناعة المحتوى متعدد اللغات والتوطين الثقافي.

- التجربة الحية: https://balagh.findapply.com
- توثيق الـ API: https://balagh.findapply.com/api/docs

## المشكلة

صانع المحتوى الدعوي الذي يستعين بنموذج لغوي يحصل على سيناريو مقنع في ثوان، لكنه لا يعرف هل الآية بلفظها، وهل الحديث في مصدره، وهل بقي المعنى كما هو حين نُقل النص إلى جمهور آخر. التحقق اليدوي من كل اقتباس وكل ترجمة يأخذ وقتا أطول من الكتابة نفسها.

## ما يفعله بلاغ

1. **يقترح ثلاث أفكار** لفيديو قصير من موضوع يكتبه المستخدم، أو يقترح المواضيع بنفسه حسب الجمهور.
2. **يوثّق النصوص قبل الكتابة:** كل آية أو حديث تعتمد عليه الفكرة يُبحث عنه في القرآن الكريم والصحيحين. ما لم يوجد يُعلَّم "غير موثّق" ولا يُستعمل.
3. **يكتب السيناريو** بمشاهد موقّتة، ويُدرج النظام النص الشرعي حرفيا من المصدر، لا النموذج.
4. **يوطّن السيناريو** لجمهور آخر (لغة، ثقافة، مستوى معرفة بالإسلام): يتغير أسلوب الشرح والأمثلة، ولا يتغير ما يُدّعى.
5. **يراجع** بثلاثة مراجعين آليين: علمي، وجمهور، ومعنى (يقارن النسخة الموطّنة بالأصل ادعاءً ادعاءً).
6. **يصحّح** في نسخة جديدة حسب الملاحظات، ثم **يعتمد الإنسان** النسخة قبل التصدير. المراجعة على قدر الخطر: صانع المحتوى وحده في الحالات العادية، ومراجع شرعي للمسائل الخلافية، ومراجع لغوي للنسخ الموطّنة ([التفاصيل](docs/human-review.md)).

اللغات في هذه النسخة: العربية (بلهجاتها) والإنجليزية.

## كيف تُضمن الموثوقية

هذه الضوابط مطبقة في الكود، لا في تعليمات النموذج وحدها:

| الضابط | التطبيق |
|---|---|
| لا نص شرعي من ذاكرة النموذج | النموذج يضع علامة مثل `{{Q1}}` والنظام يُدرج النص من `data/` |
| الشرح مسنود إلى مصدر معتمد | تفسير الميسر للآية، وشرح الموسوعة الحديثية للحديث: يُمنع النموذج من تجاوزه، ويفحصه المراجع العلمي، ويراه المراجع البشري |
| القرآن يُقتبس حرفيا فقط | السيناريو الذي يعتمد على آية دون اقتباسها يُرفض ويعاد توليده |
| لفظ الحديث المقتبس مطابق | يُتحقق أن اللفظ مقطع متصل من نص الحديث، وإلا رُفض السيناريو |
| الترجمة ليست من النموذج | في الإنجليزية يُدرج النظام ترجمة جاهزة من المصدر |
| لا فتوى شخصية | يُصنَّف كل طلب على مستويات المحتوى الأربعة؛ المستوى (د) يُحال إلى مختص ولا يُولَّد له محتوى |
| تمييز النص من الشرح | الاقتباس بين «» ومربوط بمصدره؛ المراجع تذكر "اقتباس حرفي" أو "بالمعنى" |
| مصطلحات مضبوطة | قاموس ملزم من الحزمة العلمية، وفحص آلي في النسخة الموطّنة |
| الشفافية | إفصاح ثابت بأن المحتوى مولَّد بالذكاء الاصطناعي، وأن المراجعة الآلية أولية |
| القرار للإنسان | التصدير مقفل حتى يوقّع كل من تتطلبه النسخة باسمه وصفته؛ كل تصحيح يُنتج نسخة بلا اعتمادات |

المصادر وتراخيصها وطريقة استعمالها في [SOURCES.md](SOURCES.md).

## النتائج

تقييم على 16 موضوعا و6 أسئلة فتوى و28 خطأ مزروعا ([التفاصيل والحدود](eval/RESULTS.md)):

| القياس | النتيجة |
|---|---|
| اقتباسات بلاغ المطابقة حرفيا للمصدر | 10 من 10 |
| اقتباسات الحديث في النموذج وحده المطابقة حرفيا لنص الصحيحين | 10 من 15 |
| أسئلة الفتوى الشخصية التي أُحيلت | 6 من 6 |
| أخطاء مزروعة كشفها المراجعون | 28 من 28 |
| سيناريوهات سليمة عُلّمت خطأً | 0 من 8 |

النموذج وحده لم يختلق نصا في هذه العينة، واقتباساته القرآنية كانت كلها مطابقة. ما يضيفه بلاغ هو الضمان والتتبع، لا تصحيح اختلاق شائع. العينة صغيرة والتشغيل واحد، ولم يراجع مختص شرعي المخرجات بعد.

## التقنيات

| الجزء | التقنية |
|---|---|
| الـ API | Python، FastAPI، Pydantic |
| التوليد | Gemini (`gemini-pro-latest`) بمخرجات منظّمة |
| المراجعون | Gemini (`gemini-flash-latest`)، ثلاثة طلبات متوازية |
| التحقق من النصوص | بحث ومطابقة محليان في `app/sources.py`، دون نموذج |
| التخزين | SQLite، أو Postgres عبر `DATABASE_URL` |
| الواجهة | React، TypeScript، Vite |

دور الذكاء الاصطناعي: اقتراح الزوايا، والصياغة بلغة الجمهور، والتكييف الثقافي، والمراجعة الأولية. ما لا يُترك له: نص الآية والحديث، ونسبته، وترجمته، وقرار النشر.

## التشغيل محليا

المتطلبات: Python 3.10 أو أحدث مع [uv](https://docs.astral.sh/uv/)، و Node.js 20 أو أحدث، ومفتاح Gemini API.

```bash
# الـ API
cp .env.example .env        # ثم ضع GEMINI_API_KEY
uv sync
uv run fastapi dev app/main.py --port 8010

# الواجهة، في طرفية أخرى
cd web
npm install
npm run dev                 # http://localhost:5173
```

بدون uv: `python -m venv .venv && .venv/bin/pip install -r requirements.txt`.

### المتغيرات

| المتغير | الوظيفة | الافتراضي |
|---|---|---|
| `GEMINI_API_KEY` | مفتاح Gemini (مطلوب) | |
| `REELS_MODEL` | نموذج التوليد | `gemini-pro-latest` |
| `REELS_REVIEW_MODEL` | نموذج المراجعين | `gemini-flash-latest` |
| `DATABASE_URL` | قاعدة Postgres بدل SQLite | `data/balagh.db` |
| `CORS_ORIGINS` | عناوين الواجهة المسموحة، مفصولة بفواصل | `http://localhost:5173` |
| `REELS_FALLBACK_MODEL` | النموذج البديل حين يبلغ الأساسي حدّه | قيمة `REELS_REVIEW_MODEL` |
| `VITE_API_URL` (في `web/`) | عنوان الـ API | `http://127.0.0.1:8010` |

النشر على الخادم موثق في [deploy/README.md](deploy/README.md).

## الـ API

| الطلب | الوظيفة |
|---|---|
| `POST /projects` | الطلب: الفكرة (اختيارية)، الجمهور، اللغة، المنصات، المدة. يعيد ثلاث أفكار مع أدلتها الموثّقة |
| `GET /projects/{id}` | المشروع كاملا |
| `POST /projects/{id}/ideas/{idea_id}/script` | سيناريو كامل للفكرة |
| `POST /projects/{id}/scripts/{script_id}/localize` | توطين السيناريو لجمهور آخر |
| `POST /projects/{id}/scripts/{script_id}/review` | المراجعة الآلية |
| `POST /projects/{id}/scripts/{script_id}/revise` | تصحيح في نسخة جديدة |
| `POST /projects/{id}/scripts/{script_id}/approve` | اعتماد بشري للنسخة باسم وصفة (صانع المحتوى، مراجع شرعي، مراجع لغوي) |

## بنية المستودع

```

web/        واجهة React

```

## ما أُنجز وما لم يُنجز

أُنجز خلال أيام التحدي (4 إلى 6 أكتوبر 2026) كل ما في هذا المستودع.

لم يُنجز بعد، وهو في [خطة الاستمرار](docs/roadmap.md):

- وضع الأطفال والسلاسل القصصية بشخصيات ثابتة.
- البدء من محاضرة أو نص أو رابط فيديو.
- مخرجات غير سيناريو الفيديو القصير (منشور نصي، شرائح، حلقة صوتية)، وتركيب الفيديو والصوت.
- لغات غير العربية والإنجليزية.
- مصادر غير القرآن والصحيحين (بقية كتب السنة بدرجاتها، التفسير، السيرة)، وقاموس مصطلحات أوسع.
- مراجعة مختص شرعي ومتحدث أصلي للمخرجات، واختبار مع الجمهور المستهدف.

## تكلفة التشغيل

كل سيناريو كامل (أفكار، سيناريو، توطين، مراجعة، تصحيح) يستهلك نحو 7 طلبات للنموذج، ويستغرق بين دقيقتين وثلاث. خدمة الـ API تستهلك نحو 250 ميغابايت من الذاكرة على الخادم الحي، أغلبها بيانات المصادر. التكلفة الفعلية بالعملة لم تُقَس بعد.
